# porto

Source of my research portfolio: <https://yohanesleo5890.github.io/porto/>

A single static page (`index.html`) with a few images in `assets/`. No build step.

## Publish

Settings → Pages → Source: *Deploy from a branch* → Branch `main`, folder `/ (root)`.

## Update

- Edit text directly in `index.html`. Each project is one `<article class="proj">` block.
- Change the "Last updated" date in the footer.
- To add the CV, Google Scholar, ORCID or LinkedIn buttons, put `cv.pdf` in this folder and uncomment the links in the header.

`drafts/` holds working notes that are not part of the site.
